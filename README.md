# Penthouse Wohnung 10 – 3D-Rundgang

Interaktiver 3D-Rundgang (Three.js) durch die Penthouse-Wohnung 10 mit Dachterrasse.

- Deutsch: `index.html`
- Українською: `uk.html`

Steuerung: WASD / Pfeiltasten oder Joystick zum Gehen, Maus ziehen bzw. wischen zum Umsehen,
Türen anklicken zum Öffnen/Schließen, „Grundriss“ für die Ansicht von oben.
Alles ist in den HTML-Dateien enthalten – keine Installation, funktioniert auch offline.
